Add a user-configurable option in Checkbox settings to show or hide the extra bullet before a task checkbox. Default to the current appearance (bullet shown); enabling the option hides the extra bullet. Preserve standard Markdown task-list syntax.

**Why:** the user wants the cleaner checkbox appearance to be optional because it is a personal preference.

**How to apply:** expose this as a setting rather than hard-coding the rendering; confirm the default before implementation.

---
name: Callout heading alignment
description: User-defined fixed layout for wrapped callout headings.
---

In callouts, keep the icon in its own gutter and align every wrapped heading line with the first heading text after the icon, as shown in the user's screenshot. This alignment is always applied and is not a user setting.

**Why:** the user specified the screenshot's alignment as the intended callout layout, not an optional style.

**How to apply:** align wrapped heading text to the first heading text position while preserving the icon gutter; do not align it under the icon or expose a toggle.

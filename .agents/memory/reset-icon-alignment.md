---
name: Reset icon alignment
description: User-confirmed right-column alignment for reset controls in settings rows.
---

Align every preference reset icon in the same far-right column. On slider rows, keep the numeric value immediately to the icon's left.

**Why:** the user confirmed the target after reviewing a screenshot that showed slider reset arrows shifted left of other reset arrows.

**How to apply:** adjust the slider preference widget row so the value and reset icon fit to the right of the track, with the reset icon aligned to the other preference reset icons.

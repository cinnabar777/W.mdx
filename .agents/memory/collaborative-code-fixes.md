---
name: Collaborative code fixes
description: The user's expectation for diagnosing and fixing ambiguous UI or settings issues.
---

Before making a fix when the symptom or intended behavior is unclear, inspect the relevant code and evidence, explain the concrete finding and planned scope, and align with the user. Avoid speculative fixes and repeated trial changes.

**Why:** The user explicitly asked to collaborate before proposing fixes after assumptions led to settings changes that did not match what they wanted.

**How to apply:** For ambiguous UI or settings reports, inspect the affected screen/code first; if the evidence does not identify one narrow cause, ask the user to clarify before editing.

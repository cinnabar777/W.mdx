This is a work in progress. I haven't decided if I will open source this project or not. Most likely not for a while. 

What is it? It is a WYSIWYG markdown editor using codemirror 6 for Android. It is the continuation of my [CKE5md](https://github.com/cinnabar777/CKE5md) experiment. I used Jules and Replit for the development, however, Replit went a little off during the last few sessions during a major design change and added many bugs. While it is functional there are lots of little issues and there is still a lot left to integrate, and I'm on a break from developing it for a little while. If you like the project and want to contribute just add an issue.
